🎛️ Wave Lab

Free Tool No Install Web Audio WAV Export

Wave Lab runs entirely in your browser using the Web Audio API — no download, no plugin, no account needed. Generate a tone from scratch using sine, square, sawtooth or triangle waves, or load your own audio file and shape it with pitch, volume, filter and echo controls. Export the result as a WAV file when you're done.

It's a good way to hear the difference between waveforms before you open a synth plugin in REAPER — and useful for quick sound design experiments without launching your DAW.
