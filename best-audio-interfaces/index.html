How to choose an audio interface for REAPER

REAPER isn't fussy about hardware. Almost any modern USB interface will work. What matters is matching the interface to what you record and making sure it has solid drivers. Check these five things before you buy:

  • Number of inputs. Recording one thing at a time (vocals or guitar)? One input is enough. Vocals and guitar together, or a stereo keyboard? Get two. Recording a band or drums? You'll need 4–8 or more. See how many audio interface inputs you need.
  • Drivers (Windows). Look for a dedicated ASIO driver from the manufacturer. That's the single biggest factor in low latency and crackle-free recording on Windows. On Mac, class-compliant Core Audio interfaces work without installing anything.
  • Mic preamps and phantom power. If you'll use a condenser microphone, you need 48V phantom power, which almost every interface on this page has. Cleaner preamps with more gain make a real difference with quieter dynamic mics.
  • Direct monitoring. A direct monitor switch or knob lets you hear yourself with zero delay while recording. That's essential if your computer isn't very powerful.
  • Loopback (nice to have). Loopback lets you record or stream your computer's audio alongside your mic. It's great for tutorials, podcasts and livestreams.

How to set up your audio interface in REAPER (5 minutes)

  1. Install the driver first (Windows), from the manufacturer's website. Mac users can usually skip this.
  2. Plug the interface directly into your computer, not into a USB hub.
  3. In REAPER, open Options → Preferences → Audio → Device.
  4. Set Audio system to ASIO (Windows) or Core Audio (Mac), then choose your interface as the device.
  5. Tick Request sample rate and set it to 48000 (or 44100). Either is fine. Just keep it consistent across a project.
  6. Tick Request block size and start at 128 samples for recording.
  7. Click OK, create a track, choose your input, arm the track for recording, and turn on record monitoring if you want to hear REAPER's effects while you play.

Fixing crackles, pops and latency in REAPER

Crackling and delay are the most common audio interface problems. Work through these in order:

  • Raise the block size. Crackles usually mean the buffer is too small for your computer. Try 256 or 512 samples. Use a small buffer (64–128) while recording and a large one (512–1024) while mixing.
  • Use the manufacturer's ASIO driver, not WASAPI or a generic driver like ASIO4ALL, whenever one is available.
  • Use direct monitoring on the interface while recording, so you hear yourself with no delay at all.
  • Turn off power saving. On Windows, choose the High Performance power plan. On laptops, plug into mains power.
  • Try a different USB port, ideally one directly on the computer, and update your interface's driver and firmware.
  • Freeze heavy tracks. Big synths and reverbs use a lot of CPU. Right-click a track and choose Freeze tracks to lighten the load. You can watch CPU use under View → Performance Meter.

Audio interface for REAPER: FAQ

Do I need an audio interface to use REAPER?

No. REAPER runs fine with your computer's built-in audio for editing and mixing. But to record microphones or guitar with good quality and low latency, an audio interface is the biggest upgrade you can make.

Should I use ASIO4ALL with REAPER?

Only as a fallback. If your interface has its own ASIO driver, use that. It's more stable and gives lower latency. ASIO4ALL is useful for basic devices that don't come with a dedicated driver.

What buffer (block) size should I use in REAPER?

Start at 128 samples for recording. If you hear crackles, go up to 256. For mixing large projects, use 512 or 1024. Latency doesn't matter much when you're not recording.

Is one input enough?

If you only ever record one source at a time, yes. Most people end up wanting to record vocals and guitar (or a stereo keyboard) together, so a two-input interface is usually the safer buy.

Should I record at 44.1 kHz or 48 kHz?

Either works well. 48 kHz is the standard for video and YouTube, and 44.1 kHz is the traditional music standard. Pick one and stay consistent within each project.

Do audio interfaces work on both Windows and Mac with REAPER?

All the interfaces on this page work with REAPER on both Windows and macOS. Windows users should install the manufacturer's ASIO driver. Most work on Mac without any driver.
